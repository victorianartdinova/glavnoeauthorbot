# 🎯 КРАТКАЯ СПРАВКА (One-Pager)

## Что такое Главное Автор?

**Автоматизированная система создания контента для лидгена в недвижимости через AI**

Telegram бот, который генерирует посты, ТЗ для дизайнеров, контент-планы и отчёты через Claude с учётом контекста вашего бизнеса.

---

## 📊 Основные KPI

| Метрика | Результат |
|---------|-----------|
| **Скорость генерации** | 70% быстрее чем вручную |
| **Форматов контента** | 8 разных типов постов |
| **Клиентов поддержка** | Неограниченно (сейчас 3) |
| **Интеграций** | 8+ внешних API |
| **Время развёртывания** | 5 минут на нового клиента |

---

## 💼 Основной сценарий использования

```
1️⃣  Маркетолог нажимает "📝 Пост"
    ↓
2️⃣  Выбирает формат (лидген, кейс, мем, etc.)
    ↓
3️⃣  Выбирает лот недвижимости
    ↓
4️⃣  Бот генерирует пост через Claude (10-30 сек)
    ↓
5️⃣  Маркетолог нажимает "🎨 Дизайн"
    ↓
6️⃣  ТЗ автоматически отправляется дизайнеру в рабочий чат
    ↓
7️⃣  Пост готов к публикации
```

**Вся операция: 1-2 минуты вместо 30-60 минут вручную**

## 💪 Ключевые преимущества

### ⏱️ **Экономия времени**
- Вместо 30-60 минут на пост → 1-2 минуты
- Вместо 8 часов на план → 20 минут
- Вместо 2 часов на отчёт → 3 минуты

### 💰 **Доход**
- Больше постов = больше лидов
- Оптимизированный контент = выше конверсия
- Быстрый go-to-market = меньше простоев

### 🎯 **Качество**
- AI генерирует с учётом вашего профиля (400+ реальных постов)
- Контекст встроен в каждый пост
- Автоматический анализ истории (избегаем повторов)
- Проверка соответствия Telegram Ads

### 👥 **Управление**
- **Один интерфейс** для всех операций
- **Полная история** контента
- **Метрики** в реальном времени
- **Интеграция** с рабочим чатом

### 🔄 **Масштабируемость**
- Неограниченное количество клиентов
- Кастомизация под каждого
- Автоматизация рутины
- API для интеграций

## 🔧 Что нужно для включения?

### Для нового клиента:
1. Заполнить **PROFILE.md** (2 минуты)
2. Загрузить **историю постов** (1 час)
3. Создать **GOALS.md** (30 минут)
4. Добавить **API-токен TG Booster** (2 минуты)
5. **Запустить бота** (2 минуты)

**Итого: 1.5 часа одноразово на клиента**

## 💻 Технический стек

- **Language:** Python 3.10+
- **Bot Framework:** aiogram 3.14.0
- **AI:** Claude API (claude-sonnet-4)
- **Storage:** JSON (не требует БД)
- **Scheduler:** APScheduler
- **Parsing:** BeautifulSoup4, Playwright

## Основные интеграции в деталях

### Claude API (Anthropic)
- **Модель:** claude-sonnet-4-20250514 (claude-opus для важного)
- **Timeout:** 120 сек
- **Использование:**
  - Генерация 8 форматов контента
  - Валидация тем
  - Редактирование текстов (жёстче/мягче)
  - Анализ метрик

### Telegram API (aiogram 3.x)
- **Библиотека:** aiogram==3.14.0
- **Возможности:**
  - Polling (обновления от бота)
  - FSM (состояния диалога)
  - Inline кнопки (callback-кнопки)
  - Reply клавиатуры (меню внизу)
  - Отправка в чаты/темы

### TG Booster (CPA-сеть)
- **Функции:**
  - Загрузка метрик по кампаниям
  - Расчёт CPL (стоимость лида)
  - ROI анализ

### Яндекс Поиск + SerpAPI
- **Технология:** Playwright браузер + SerpAPI
- **Функции:**
  - Парсинг результатов поиска об объектах
  - Извлечение локации, инфраструктуры, транспорта
  - Обход защиты от ботов

### Парсинг сайтов ЖК
- **Технология:** BeautifulSoup + aiohttp
- **Функции:**
  - Извлечение цен, планировок, метро
  - Анализ особенностей объектов

### Telegram Parser (Мемы)
- **Источник:** `/root/telegram-parser/output/scraped_posts.json`
- **Функции:**
  - Парсинг топ-мемов из Telegram
  - Фильтрация по датам

### APScheduler (Фоновые задачи)
- **Функции:**
  - Автоматический анализ лучших постов
  - Периодическое обновление метрик

### OpenAI Whisper (Транскрипция)
- **Функции:**
  - Распознавание речи из голосовых Telegram
  - Конвертация кружков в текст
