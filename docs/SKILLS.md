# Skills для работы с ботом

## Установленные skills

### Custom skills
1. **glavnoe-bot-dev** — контекст проекта, архитектура, текущие задачи
2. **skills-guide** — гайд по работе со skills (из вебинара)

### Superpowers (для разработки)
- `brainstorming` — мозговой штурм перед кодом
- `writing-plans` — создание детальных планов
- `executing-plans` — выполнение задач батчами
- `test-driven-development` — TDD подход
- `systematic-debugging` — системная отладка
- `verification-before-completion` — проверка перед завершением
- `subagent-driven-development` — работа через агентов
- `requesting-code-review` — запрос ревью кода
- `receiving-code-review` — получение ревью
- `finishing-a-development-branch` — завершение ветки
- `dispatching-parallel-agents` — параллельные агенты
- `using-git-worktrees` — работа с git worktrees
- `using-superpowers` — гайд по superpowers
- `writing-skills` — создание новых skills

## Как вызывать

```
Используй skill glavnoe-bot-dev и добавь команду /brief для генерации ТЗ
```

## Расположение

**Персональные** (работают везде):
```
~/.claude/skills/
```

**Проектные** (только в glavnoe-bot):
```
/root/glavnoe-bot/.claude/skills/
```

## Когда использовать glavnoe-bot-dev

- Перед началом работы над новой функцией
- Нужен контекст клиента (Apple Real Estate)
- Интеграция Claude API
- Работа с multi-client архитектурой
