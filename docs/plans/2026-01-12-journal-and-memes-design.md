# Дизайн: Журнал контента + Мемы

**Дата:** 2026-01-12
**Статус:** Утверждён

---

## Проблемы

1. Произвольный пост (/post) не добавляется в контент-план
2. Нет возможности генерировать мемы
3. Нет единого места, где видно что опубликовано + что запланировано

---

## Решение

### 1. Журнал контента

**Концепция:** Двусторонний план — не только "что сделать", а "что сделано + что запланировано"

**Хранение:** `data/content_journal/{client_id}/journal.json`

**Структура записи:**
```json
{
  "id": "uuid",
  "date": "2026-01-12",
  "format": "lidgen|case|meme|expert|digest|live|circle|podcast",
  "text": "Полный текст поста",
  "status": "planned|published",
  "source": "bot_generated|forwarded|from_plan",
  "created_at": "2026-01-12T10:30:00"
}
```

**Изменения:**

1. **/post** — после генерации:
   - Спрашивает дату публикации (кнопки: Сегодня / Завтра / Выбрать)
   - Сохраняет в журнал со статусом `published`

2. **Пересылка поста** — новый хендлер:
   - Пользователь пересылает готовый пост в бота
   - Бот спрашивает формат (кнопки с форматами)
   - Бот спрашивает дату публикации
   - Сохраняет в журнал

3. **/journal** — просмотр журнала:
   - Показывает календарь на текущую неделю
   - Цветовая маркировка: опубликовано / запланировано
   - Кнопки навигации по неделям

---

### 2. Мемы (/meme)

**Источник референсов:** `/root/telegram-parser/output/scraped_posts.json`

**Флоу:**
1. `/meme` → бот читает scraped_posts.json
2. Фильтрует посты за 7 дней по критериям "мемогенности"
3. Показывает 3 референса кнопками
4. Пользователь выбирает
5. Бот генерит адаптацию + ТЗ дизайнеру
6. Сохраняет в журнал как формат "meme"

**Критерии мемогенности:**
- Длина < 500 символов
- Есть эмодзи или восклицания
- Темы: цены, ипотека, выбор, ожидание vs реальность

**Выход генерации:**

```
МЕМНЫЙ ПОСТ

[Адаптированный текст под ЦА клиента]

---

ТЗ ДИЗАЙНЕРУ

ИДЕЯ: [описание концепции мема]
ТЕКСТ НА КАРТИНКЕ: [короткий текст]
ВИЗУАЛ: [что изобразить / стиль]
РЕФЕРЕНС: [ссылка на оригинальный пост]
```

### 3. Новые файлы

```
utils/
  content_journal.py    # Работа с журналом (CRUD)
  meme_sources.py       # Чтение и фильтрация референсов

handlers/
  journal_handler.py    # /journal, пересылка постов
  meme_handler.py       # /meme
```

---

### 4. Изменения в существующих файлах

**handlers/content_handler.py:**
- После генерации поста вызывать `journal.add_entry()`

**bot.py:**
- Зарегистрировать journal_handler, meme_handler
- Добавить хендлер на пересланные сообщения

---

## Не делаем

- Не меняем telegram-parser (просто читаем его output)
- Не делаем автопостинг (только генерация)
- Не делаем аналитику мемов (пока)

---

## Команды после реализации

- `/post` — генерация поста (+ сохранение в журнал)
- `/meme` — генерация мема из референсов
- `/journal` — просмотр журнала контента
- Пересылка поста → сохранение в журнал
