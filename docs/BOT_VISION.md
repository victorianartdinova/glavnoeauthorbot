# Glavnoe Bot - Vision & Goals

## Цель
**Автоматизировать создание контента для агентства лидгена в недвижимости (премиум-сегмент)**

Вместо ручного написания постов, ТЗ, контент-планов — бот генерирует всё через Claude API с учётом контекста клиента.

---

## Видение
Telegram-бот как "второй мозг" для контент-менеджера агентства:
- **Знает клиентов** — ToV, ЦА, форматы, эмодзи, ветки чатов
- **Генерирует контент** — посты, ТЗ дизайнеру, кружки, подводки
- **Планирует** — контент-планы на неделю с календарём
- **Ведёт журнал** — что опубликовано, что запланировано
- **Отправляет команде** — в рабочий чат с тегами исполнителей

---

## Основные функции

### 1. Генерация контента
| Команда | Что делает |
|---------|-----------|
| `/post` | Пост (лидген-карточка, кружок, дайджест, эксперт, мем) |
| `/brief` | ТЗ дизайнеру — 3 варианта текстов для баннеров |
| `/circle` | ТЗ для записи кружка (тема + тезисы) |
| `/live` | Подводка к Instagram-материалу |
| `/voice_intro` | Подводка к голосовому/подкасту |
| `/meme` | Адаптация мемов под недвижимость |

### 2. Планирование
| Команда | Что делает |
|---------|-----------|
| `/plan` | Контент-план на 7 дней (календарь с кнопками) |
| `/journal` | Журнал контента (календарь опубликованного) |

### 3. Командная работа
- Отправка постов/ТЗ в рабочий чат
- Теги дизайнера и оператора
- Ветки по клиентам

### 4. Multi-client архитектура
- 3 клиента: apple_real_estate, artem_solodkov, nadejda_dmitruk
- Отдельный контекст для каждого (ToV, эмодзи, ЦА)
- Переключение одной кнопкой

---

## Стек
- **aiogram 3.x** — Telegram Bot API
- **Claude API** — генерация контента
- **JSON/Markdown** — хранение (без БД)
- **telegram-parser** — источник мемов

---

## Что НЕ делает бот
- Транскрипция аудио (нужен внешний сервис)
- Публикация постов в канал (только генерация)
- Работа с CRM/базой лотов (ручной ввод)

---

## Уникальность
1. **Глубокий контекст клиента** — ToV из анализа сотен постов
2. **8 форматов контента** — не просто "напиши пост"
3. **B2B2C модель** — бот для агентства, а не конечного клиента
4. **Интеграция с командой** — рабочий чат, теги, ветки
