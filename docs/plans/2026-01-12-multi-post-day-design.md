# Дизайн: Несколько постов в день + защита ЛИДГЕН

## Проблема

1. Сейчас 1 день = 1 пост
2. ЛИДГЕН-тему можно заменить на что угодно (мем, прогрев) — теряется лидген-пост
3. Нет возможности добавить прогревочный пост к ЛИДГЕН-дню

## Решение

### 1. Структура дня: 1 день = N постов

```
День 1 (13.01.2026):
├── [ЛИДГЕН] ЖК Легенда, от 25 млн     ← основной, защищён
├── [ПРОГРЕВ] Мем про выход с праздников ← дополнительный
└── + Добавить пост
```

### 2. Типы постов

| Тип | Редактирование темы | Удаление |
|-----|---------------------|----------|
| ЛИДГЕН | Только на другой объект (валидация Claude) | Нельзя |
| ПРОГРЕВ | Свободно | Можно |
| ЖИВОЙ | Свободно | Можно |
| МЕМ | Свободно | Можно |

### 3. Валидация ЛИДГЕН через Claude

При редактировании темы ЛИДГЕН-поста:
1. Отправить новую тему в Claude с промптом: "Это объект недвижимости (ЖК, лот, подборка объектов)?"
2. Если НЕТ → отклонить: "Это не объект недвижимости. Введи ЖК/лот/подборку"
3. Если ДА → сохранить

### 4. Действия с днём (новый UI)

```
📆 День 1 (13.01.2026, Пн)

📍 [ЛИДГЕН] ЖК Легенда, от 25 млн
   [✏️ Редакт.] [📝 Пост] [🎨 ТЗ]

🔥 [ПРОГРЕВ] Мем про праздники
   [✏️ Редакт.] [📝 Пост] [🗑 Удалить]

[➕ Добавить пост]
[⬅️ Назад к плану]
```

### 5. Добавление поста

При нажатии "Добавить пост":
1. Выбор типа: ПРОГРЕВ / ЖИВОЙ / МЕМ (без ЛИДГЕН — он уже есть)
2. Ввод темы (свободный текст)
3. Пост добавляется к дню

## Изменения в данных

### Было (plan.json):
```json
{
  "days": [
    {
      "day": 1,
      "date": "13.01.2026",
      "format": "ЛИДГЕН",
      "topic": "ЖК Легенда",
      "status": "pending"
    }
  ]
}
```

### Стало:
```json
{
  "days": [
    {
      "day": 1,
      "date": "13.01.2026",
      "posts": [
        {
          "id": "post_1",
          "format": "ЛИДГЕН",
          "topic": "ЖК Легенда, от 25 млн",
          "protected": true,
          "status": "pending"
        },
        {
          "id": "post_2",
          "format": "ПРОГРЕВ",
          "topic": "Мем про выход с праздников",
          "protected": false,
          "status": "pending"
        }
      ]
    }
  ]
}
```

## Файлы для изменения

1. `utils/plan_storage.py` — новая структура данных
2. `handlers/plan_handler.py` — UI для нескольких постов + валидация
3. `handlers/content_handler.py` — генерация плана с новой структурой

## Миграция

Старые планы конвертируются автоматически:
- `format` + `topic` → `posts: [{ format, topic, protected: format=="ЛИДГЕН" }]`
