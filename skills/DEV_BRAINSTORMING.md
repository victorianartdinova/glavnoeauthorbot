# SKILL: Dev Brainstorming

**Scope:** ТОЛЬКО разработка GLAVNOE BOT

## Что делает

Превращает любой вход (боль/идея/баг) в готовые dev-элементы бэклога.

## Вход → Выход

**Вход:**
- "что бесит" / "что сломано" / "что хочу"
- текст в свободной форме

**Выход:**
1. ОШИБКА (1 строка) — если это баг
2. TASK PACK — готовая задача для бэклога:
   - title
   - type (bug/feature/debt)
   - priority (P0-P3)
   - acceptance_criteria (опционально)

## Приоритеты

| Priority | Область |
|----------|---------|
| P0 | Память, статусы, неповторы (критичная инфраструктура) |
| P1 | UX — блокирует пользователя |
| P2 | Качество редактора, улучшения |
| P3 | Метрики, nice-to-have |

## Автоматическое определение

Ключевые слова → автоматический тип и приоритет:

**Баги (bug):**
- "баг", "bug", "сломано", "не работает", "ошибка", "error"
- Дефолтный приоритет: P1

**Tech debt (debt):**
- "рефактор", "долг", "debt", "переписать"
- Дефолтный приоритет: P2

**Фичи (feature):**
- Всё остальное
- Дефолтный приоритет: P2

**Повышение до P0:**
- "критично", "срочно", "urgent", "p0", "память", "статус"

**Повышение до P1:**
- "важно", "p1", "ux"

## Дедупликация

- Нормализация заголовка (lowercase, без пунктуации)
- MD5 хеш первых 16 символов
- Если хеш совпадает с существующей активной задачей → обновляется `last_seen_context`, новая не создаётся

## Использование

### В боте (Telegram)

```
/dev — открыть меню бэклога
```

Кнопки:
- ➕ Добавить — новая задача
- 📋 Список P0 — критичные
- 🔄 В работе — текущие
- 🔍 Поиск — найти задачу
- 📊 Статистика — сводка
- 🔄 Sync MD — синхронизировать файлы

### Программно

```python
from utils.dev_backlog import create_from_feedback, backlog_store, sync_backlog_to_md

# Создать из фидбека (автоопределение типа/приоритета)
task = create_from_feedback("баг: кнопка не работает")

# Создать вручную
task_id = backlog_store.create(
    title="Добавить экспорт в PDF",
    type="feature",
    priority="P2"
)

# Изменить статус
backlog_store.set_status(task_id, "in_progress")

# Синхронизировать MD
sync_backlog_to_md()
```

## Правила

1. **Без вопросов к пользователю** — если данных нет, добавь шаг discovery в acceptance_criteria
2. **Без воды** — краткий title, детали в notes
3. **Автосинк** — при завершении задачи MD обновляются автоматически
4. **Память** — бэклог персистентный, не теряется между сессиями
