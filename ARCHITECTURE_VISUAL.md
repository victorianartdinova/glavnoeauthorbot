```
┌─────────────────────────────────┐

└────────────┬────────────────────┘

│  или добавление нового           │

             │
             ▼
┌──────────────────────────────────────────────────────┐
│  CLAUDE API - Генерация контента                    │
├──────────────────────────────────────────────────────┤
│                                                      │
│  Собирается контекст:                              │
│  ├─ Профиль клиента (PROFILE.md)                  │

│  ├─ История 50+ постов (anti_repeat.json)       │
│  ├─ Запрещённые фразы (banned_phrases.json)     │
│  └─ Лот для поста                                │
│                                                      │

│  ↓                                                   │
│  claude-sonnet-4-20250514                          │
```

## Резюме архитектуры

| Компонент | Технология | Назначение |
|-----------|-----------|-----------|
| **Core Bot** | aiogram 3.14.0 | Telegram интеграция |
| **AI Engine** | Claude API | Генерация контента |
| **Storage** | JSON + FS | Хранение данных |
| **Search** | Yandex + SerpAPI | Поиск информации |
| **Parsing** | BeautifulSoup4 | JK сайты, мемы |
| **Analytics** | TG Booster API | Метрики |
| **Scheduler** | APScheduler | Фоновые задачи |
| **Speech** | OpenAI Whisper | Транскрипция |
| **HTTP** | aiohttp | API запросы |

---

**Архитектура оптимизирована на:**
- ✅ Быстроту генерации контента
- ✅ Простоту развёртывания (JSON storage)
- ✅ Масштабируемость (multi-client)
- ✅ Надёжность (error handling, timeouts)
- ✅ Интеграции (8+ API)
