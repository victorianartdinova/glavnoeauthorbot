## Задача 2: Ручное добавление постов в журнал

### Flow
1. `/journal` показывает календарь + кнопка "➕ Добавить пост"
2. Выбор формата (существующая клавиатура)
3. Ввод темы/описания текстом
4. Выбор даты: сегодня / вчера / ввести вручную (ДД.ММ)
5. Сохранение с подтверждением

### Новые состояния FSM
- `waiting_for_manual_format`
- `waiting_for_manual_topic`
- `waiting_for_manual_date`

### Изменения в клавиатуре журнала
```
[⬅️ Пред. неделя] [След. неделя ➡️]
[📆 Текущая неделя]
[➕ Добавить пост]
```

### Формат сохранения
- `status: "published"`
- `source: "manual"`
- `text` = введённая тема

### Файлы
- `handlers/journal_handler.py` — новая кнопка + flow

---

## Задача 3: Ввод даты вручную

### Решение
Кнопка "Выбрать дату" → ввод текстом.

### Форматы ввода
- `15.01` → 15 января текущего года
- `15.01.2026` → полная дата
- `15` → 15-е текущего месяца

### Валидация
- Проверка формата regex
- Ошибка → "Неверный формат. Введи дату как 15.01"

### Файлы
- `handlers/journal_handler.py` — состояние + парсер даты
