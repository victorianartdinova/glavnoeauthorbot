- **Фон:** Темно-синий (#2C3E50) / Темно-зеленый (#1A3A3A) / Реальное фото проекта
- **Акцент:** Оранжевый (#FF6B35) — для плашек с офферами

- **Логотип:** Apple Real Estate (стандартный, белый или цветной на прозрачном фоне)

### Шрифты
- **Заголовки:** Жирный, sans-serif (аналог Montserrat Bold / Gotham Bold)
- **Текст в плашках:** UPPERCASE, жирный
- **Основной текст:** Белый, крупный, читаемый (минимум 48px для заголовка)

- **Требования:** Реальное фото проекта (не стоковое)
- **Время суток:** Вечер/закат (эмоциональная атмосфера, подсветка окон)
- **Ракурс:** Фасад здания, видна архитектура
- **Обработка:** Легкое затемнение для контраста с белым текстом
