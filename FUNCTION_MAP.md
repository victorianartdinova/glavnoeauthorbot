## 📈 Пример использования

### Сценарий: Создание лидген-поста в план

```
1. Пользователь нажимает "📝 Пост"
   ↓
2. Выбирает формат "Лидген-карточка"
   ↓
3. Выбирает лот из базы (или добавляет новый)
   ↓
4. Бот генерирует пост через Claude API:
   • Применяет контекст клиента
   • Исключает повторения из истории
   • Встраивает приоритеты недели
   • Использует правильный тон голоса
   ↓
5. Вариант опубликования:
   A) Редактирование: "Жёстче" / "Мягче"
   B) Нажать "🎨 Дизайн" → ТЗ отправляется дизайнеру
   C) Добавить в "📅 Контент-план"
   D) Пересылка в "📓 Журнал"
   ↓
6. Пост автоматически сохраняется в истории
   ↓
7. Система предложит избежать повторов в следующий раз
```

### Сценарий: Контент-план на неделю

```
1. "📅 Контент-план" → выбор период (7 дней)
   ↓
2. Выбор лотов/тем для недели
   ↓
3. Бот генерирует план:
   • Чередует 8 форматов
   • Только Пн-Пт
   • Встраивает приоритеты
   ↓
4. Для каждого дня:
   ├─ Показать день → кнопка "Редактировать"
   ├─ Изменить тему (если нужно)
   ├─ Кнопка "📝 Пост" → генерация
   ├─ Кнопка "🎨 Дизайн" → ТЗ дизайнеру
   └─ Кнопка "✅ Согласовать" → в рабочий чат
   ↓
5. Отправка в рабочий чат
   ↓
6. Сохранение в БД планов
```
