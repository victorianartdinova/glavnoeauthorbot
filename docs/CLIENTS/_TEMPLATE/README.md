# Шаблон папки клиента

Эта папка — **шаблон** для создания новых клиентов.

## Как использовать:

1. **Скопируй эту папку:**
   ```bash
   cp -r docs/CLIENTS/_TEMPLATE docs/CLIENTS/client_slug
   ```

2. **Заполни все файлы:**
   - `PROFILE.md` — информация о клиенте
   - `TONE_OF_VOICE.md` — стиль и голос бренда
   - `GOALS.md` — цели, KPI, стратегия
   - `CONTEXT.md` — рынок, конкуренты, аудитория

3. **Бот автоматически использует этот контекст:**
   - При добавлении лота
   - При генерации постов
   - При создании контент-планов

---

## Структура файлов:

```
client_slug/
├── PROFILE.md         # О компании, контакты
├── TONE_OF_VOICE.md   # Как писать (стиль, язык, примеры)
├── GOALS.md           # Цели, KPI, стратегия
├── CONTEXT.md         # Рынок, конкуренты, аудитория
├── WINNERS.md         # Эффективные посты (автоматически)
├── lots.json          # Лоты клиента (автоматически)
├── posts.json         # Посты (автоматически)
└── metrics.json       # Метрики (автоматически)
```

---

## Важно:

- **Заполни всё подробно** — чем больше контекста, тем лучше бот пишет
- **Обновляй ToV** — добавляй удачные примеры постов
- **Следи за метриками** — бот учится на "победителях"
