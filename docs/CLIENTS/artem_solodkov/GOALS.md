# Artem Solodkov — Цели и форматы контента

## Бизнес-цели
1. Привлечение инвесторов в коммерческую недвижимость
2. Продажа офисов и ритейла
3. Позиционирование как эксперта по инвестициям в недвижимость
4. Генерация лидов на консультации

## Форматы контента

### 1. Лидген-посты (коммерция)
- Акцент на доходности и НДС
- Конкретные цифры: доходность, срок окупаемости, НДС к возврату
- CTA на расчёт доходности

### 2. Лидген-посты (жилая)
- Инвестиционный фокус (рост цены, перепродажа)
- Для семей — только если есть выгодные условия

### 3. Экспертный контент
- Разбор инвестиционных кейсов
- Сравнение доходности разных объектов
- Налоговая оптимизация для бизнеса
- Тренды рынка коммерческой недвижимости

### 4. Кружки брокера
- Ответы на вопросы инвесторов
- Разбор конкретных объектов
- Новости рынка коммерции

## Ключевые метрики для постов
- Доходность (% годовых)
- Срок окупаемости
- НДС к возврату
- Потенциал роста цены
- Арендная ставка
