# GLAVNOE Bot — Карта для бизнеса

## Что это?
**@glavnoeauthor_bot** — это ИИ-ассистент для создания контента агентства недвижимости ГЛАВНОЕ.

Работает в Telegram, использует нейросеть Claude для генерации текстов.

---

## Какие бизнес-задачи решает

### 1. Экономия времени на контенте
| Было | Стало |
|------|-------|
| Риелтор 2-3 часа пишет пост | Бот генерирует за 30 секунд |
| Контент-план на неделю = полдня | Готовый план за 1 минуту |
| ТЗ дизайнеру = 30 минут | 3 варианта за 20 секунд |

### 2. Единый стиль коммуникации
- Бот знает TOV (tone of voice) каждого клиента
- Не забывает запрещённые слова и фразы
- Соблюдает правила Telegram Ads (суммы, формулировки)

### 3. Системная работа с объектами (лотами)
- Все ЖК и квартиры в одной базе
- Автопоиск информации о новых объектах
- Приоритизация: какие лоты продвигать на этой неделе

### 4. Аналитика и отчёты
- Метрики постов (просмотры, реакции)
- Еженедельные ретроспективы
- Отслеживание CPL (стоимость лида)

## Что умеет бот (функции)

### Главное меню
```
📝 Пост        → Создать продающий пост
🎨 ТЗ          → Задание для дизайнера (3 варианта)
📅 План        → Контент-план на 7 дней
🎙 Кружок      → Сценарий для видео/аудио
😂 Мем         → Развлекательный контент
📓 Журнал      → История всех постов
```

### Типы контента
| Тип | Для чего | Пример |
|-----|----------|--------|
| **Лидген** | Продажа конкретного объекта | "Квартира в ЖК Сочная с видом на море..." |
| **Дайджест** | Подборка нескольких объектов | "5 квартир до 10 млн в Адлере" |
| **Живой обзор** | Репортаж с локации | "Стою сейчас на крыше ЖК..." |
| **Кейс** | История покупки клиента | "Как помогли семье найти..." |
| **Анонс** | Событие, старт продаж | "Завтра открытие продаж..." |
| **FAQ** | Ответы на вопросы | "Вопрос: как купить в ипотеку?" |

### Работа с клиентами
- **3 активных клиента** сейчас:
  - Apple Real Estate (основной)
  - Артём Солодков
  - Надежда Дмитрук

- Для каждого клиента хранится:
  - Профиль компании
  - Стиль общения (TOV)
  - Цели и KPI
  - Список объектов (лотов)
  - Конкуренты для анализа

### Фокус недели
- Какие объекты продвигать в первую очередь
- Запрещённые фразы (чтобы не повторяться)
- Защита от дублей — бот помнит, что уже писал

## Автоматизация

### Что работает само
- **Авто-деплой**: новый код из GitHub → бот перезапускается
- **Рабочий чат**: готовые посты летят в командный чат
- **Ветки по клиентам**: каждый клиент в своей ветке чата

### Рабочий чат команды
Все сгенерированные посты автоматически отправляются в рабочий чат:
- Ветка Apple Real Estate
- Ветка Артём Солодков
- Ветка Надежда Дмитрук
