## 1. ОБЩЕЕ ОПИСАНИЕ

### Цепочка B2B2C
**Бот → Агентство лидгена GLAVNOE → Клиенты агентства → Клиенты клиентов**

- **Виктория (пользователь бота)** — руководитель агентства лидгена GLAVNOE
- **Бот** — инструмент для автоматизации генерации контента
- **Apple Real Estate** — основной клиент агентства (multi-client архитектура)

### Что делает бот
1. **Генерирует ТЗ для дизайнеров** — текст для баннеров Telegram Ads
2. **Пишет посты для канала** — 8+ форматов контента
3. **Создаёт контент-планы** — на 7 дней с календарём
4. **Пишет подводки к голосовым** — после транскрипции кружков/подкастов

### Стек
- Python 3.12
- aiogram 3.x (Telegram Bot API)
- Claude API (Anthropic) — модель claude-sonnet-4-20250514
- JSON + Markdown (без БД)
- Multi-client архитектура

## 7. TONE OF VOICE (Apple Real Estate)

### Общий стиль
- **Характер:** Дружелюбно-профессиональный, эмоциональный, экспертный
- **Позиция:** Доверительный советчик, защитник от ошибок
- **Формат:** Как разговор с умным другом из отрасли

### Структура постов
1. **Заголовок/Хук:** Эмодзи + Жирный вопрос + Интрига
2. **Эмодзи:** 🔥 (hot), 📍 (локация), 💰 (цена), ▪️ (маркер), ⚪️ (CTA)
3. **Форматирование:** Короткие абзацы, жирный для акцентов

### CTA-формула
⚪️ + Действие + "КЛЮЧЕВОЕ_СЛОВО" + Что получит

Примеры:
- "⚪️ Напишите 'ГОТОВО' — забронируем квартиру"
- "⚪️ Жмите 'ДОЛИНА' — отправим детали"

### Запреты
- Названия ЖК в постах и ТЗ
- Абстракции ("история встречается с будущим")
- Канцелярит
- Размеры в пикселях

## 15. АРХИТЕКТУРА FSM

### Состояния (примеры)

```python
class ContentStates(StatesGroup):
    waiting_for_brief_data = State()      # Ожидание данных для ТЗ
    waiting_for_post_format = State()     # Выбор формата поста
    waiting_for_circle_topic = State()    # Тема кружка
    waiting_for_live_link = State()       # Ссылка на Instagram

class PlanStates(StatesGroup):
    editing_topic = State()               # Редактирование темы
    editing_post = State()                # Редактирование поста
    editing_brief = State()               # Редактирование ТЗ
    waiting_for_lot_data = State()        # Данные лота для ТЗ
    adding_post_topic = State()           # Тема нового поста

class JournalStates(StatesGroup):
    waiting_for_format = State()          # Формат при пересылке
    waiting_for_date = State()            # Дата публикации
    waiting_for_manual_format = State()   # Формат вручную
    waiting_for_manual_topic = State()    # Тема вручную
    waiting_for_plan_topics = State()     # Темы для плана
```

## 16. ОСОБЕННОСТИ
