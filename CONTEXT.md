# КОНТЕКСТ ПРОЕКТА @glavnoeauthor_bot

## Цепочка B2B2C

**Бот → Агентство лидгена GLAVNOE → Клиенты агентства → Клиенты клиентов**

- **Виктория (пользователь бота)** — руководитель агентства лидгена GLAVNOE
- **Бот** — инструмент для автоматизации и оптимизации процессов генерации контента
- **Apple Real Estate** — клиент агентства (один из клиентов, multi-client архитектура)

## Что это
Telegram-бот для генерации контента для агентства недвижимости (премиум-сегмент, Москва).

## Текущий клиент
Apple Real Estate — минимальный чек 25 млн ₽, фокус на бизнес/элит-класс.

## Что бот делает
1. **Генерирует ТЗ для дизайнеров** — текст для баннеров Telegram Ads (визуалы дизайнер берёт с сайтов ЖК)
2. **Пишет посты для канала** — 8 форматов (лидген-карточки, кейсы, живой контент, подкасты)
3. **Создаёт контент-планы** — на основе лотов и рыночного контекста
4. **Пишет подводки к голосовым** — после транскрипции кружков/подкастов брокеров

## Стек
- aiogram 3.x
- Claude API (Anthropic)
- JSON + Markdown (без БД)
- Multi-client архитектура

## Структура контекста клиента
```

├── MARKET_CONTEXT.md       # Тренды рынка с источниками
├── CONTEXT.md              # Районы, цены, шаблоны
└── BANNER_BRIEF_TEMPLATE.md # Шаблон ТЗ для дизайнера
```

## 8 форматов контента
1. Лидген-карточка объекта
2. Список советов/ошибок
3. Кейс клиента
4. Вопрос-ответ/дилемма
5. Подборка объектов
6. **Живой контент из Instagram** (2-3x/неделя, подводка к материалу)
7. **Кружок от брокера** (транскрипция → подводка)
8. **Голосовой подкаст** (транскрипция → подводка)
